# Tally Counter desktop downloads

Official binary releases of **Tally Counter: Multi Clicker** for Windows and Linux, from Indragni Solutions. The app is free and has no ads.

- Website: https://livetallycounter.com/
- Privacy: https://livetallycounter.com/privacy/
- Help: support@livetallycounter.com

Downloads on each release:

- `Tally.Counter_x.y.z_x64-setup.exe` — Windows installer (checks this repository for signed updates)
- `Tally.Counter_x.y.z_amd64.AppImage` — Linux, any distribution (checks this repository for signed updates)
- `Tally.Counter_x.y.z_amd64.deb` — Debian/Ubuntu (no self-update; install the next .deb from here)
- `SHA256SUMS.txt` — checksums

The Microsoft Store and Snap Store versions update through their stores. This repository holds no source code.
